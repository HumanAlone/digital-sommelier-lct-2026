# Черновик контракта API

Это рабочая договорённость для параллельной разработки, а не описание уже готового бэкенда. Перед подключением к коду сокомандника нужно подтвердить маршруты и реальные названия полей.

Базовый путь: `/api`. Ответы — JSON. Идентификатор `id` должен быть одинаковым в каталоге, карточке и результате распознавания. В локальном каталоге фронта `id` равен полю `Slug` из CSV.

## Каталог

`GET /api/wines`

```json
{
  "items": [
    {
      "id": "slug-iz-dataset",
      "name": "Название вина",
      "winery": "Винодельня",
      "region": "Регион",
      "category": "Красное",
      "color_description": "Тёмно-рубиновый",
      "grapes": ["Каберне Совиньон"],
      "description": "Описание из датасета",
      "image_url": "/api/images/slug-iz-dataset.webp"
    }
  ]
}
```

## Карточка вина

`GET /api/wines/{id}`

Возвращает поля каталога и дополнительные поля, если они есть: `abv`, `food_pairings`, `vintage`, `country`. Отсутствующие сведения лучше возвращать как `null` или пустой массив, а не придумывать значения.

## Сканирование

`POST /api/scan` — `multipart/form-data`, поле `image` с фотографией бутылки.

```json
{
  "wine_id": "slug-iz-dataset",
  "confidence": 0.92
}
```

Если бутылка не распознана, бэкенд возвращает понятный код ошибки и сообщение; фронт показывает возможность повторить снимок или перейти к поиску.

## Аккаунт

Фронт уже показывает регистрацию и вход. Пока API не подключён, формы не создают аккаунт и сообщают об этом пользователю.

- `POST /api/auth/register` — JSON `{ "name": "Имя", "email": "user@example.com", "password": "пароль" }`.
- `POST /api/auth/login` — JSON `{ "email": "user@example.com", "password": "пароль" }`.
- Оба запроса при успехе возвращают `{ "access_token": "...", "user": { "id": "...", "name": "Имя", "email": "user@example.com" } }`.
- `GET /api/auth/me` — заголовок `Authorization: Bearer <access_token>`, ответ `{ "id": "...", "name": "Имя", "email": "user@example.com" }`.
- При ошибке ожидается HTTP 4xx и JSON `{ "detail": "Понятное сообщение" }`.

Токен хранится только в `sessionStorage` текущей вкладки; пароль фронт не сохраняет. Выход удаляет токен. Избранное, история, подборки и дневник пока остаются локальными данными браузера; их синхронизация с аккаунтом требует отдельного API.

## Изображения и интеграция

- `image_url` — публичный URL или путь относительно адреса API, который браузер может загрузить. Путь к файлу на компьютере в ответ API передавать нельзя.
- Если фронт и бэкенд работают на разных адресах при разработке, нужно настроить CORS на бэкенде или прокси на фронте.
- Сырые файлы датасета и веса моделей не класть в Git, если они большие; согласовать локальные пути хранения отдельно.
