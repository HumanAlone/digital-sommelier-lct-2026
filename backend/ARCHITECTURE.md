# Архитектура

## Обзор
Система распознаёт российские вина по фотографии этикетки. Пайплайн двухступенчатый: 
визуальный поиск + текстовый матчинг (OCR).

## Компоненты

### 1. YOLO-детекция
Находит бутылку на фото, возвращает центральный кроп. 
Игнорирует части соседних бутылок (ТЗ: «если в кадре несколько — берём центральную»).

### 2. Визуальный поиск (FAISS)
Два индекса:
- `gallery.faiss` — базовая SigLIP (recall, ширина K=100)
- `gallery_finetuned.faiss` — дообученная SigLIP (rerank, разводит near-duplicates)

Результат: линейная комбинация косинусов → сиглиповый скор ∈ [0, 1].

### 3. Текстовый матчинг (OCR)
RapidOCR на кропе → токены → IDF-скоринг по каталогу.
Фьюжн: `final = α·siglip + β·ocr_normalized`.

### 4. FastAPI-сервер
Эндпоинт `/predict` принимает multipart, возвращает плоский JSON с топ-10.

## Путь данных
Фото → YOLO (кроп) → 2× SigLIP (эмбеддинги) → FAISS (топ-100 кандидатов) 
→ OCR (скоринг) → фьюжн → JSON-карточка.

## Почему двухступенчатая схема
Основная проблема — near-duplicates (одна винодельня, одна линейка, разные сорта).
Базовая модель даёт recall, дообученная — rerank. Без второй ступени gap ≈ 0.005, 
что недостаточно для уверенного топ-1.

## Данные
- `artifacts/models/` — веса SigLIP и YOLO
- `artifacts/index/` — FAISS-индексы + JSON со слагами
- `data/catalog_cleaned.csv` — эталонный каталог
