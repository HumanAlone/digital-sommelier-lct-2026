# Ноутбуки ML-контура

Здесь лежат исследовательские ноутбуки для подготовки данных, обучения и оценки моделей. Продакшен-сервис использует готовые файлы из `backend/artifacts/`; запускать ноутбуки для обычного старта сайта не нужно.

| Ноутбук | Назначение |
| --- | --- |
| `01_dataset_preprocessing.ipynb` | Подготовка каталога и сопоставление референсных фотографий |
| `02_yolo_training.ipynb` | Обучение YOLO для выделения бутылки или этикетки |
| `03_siglip_finetune.ipynb` | Дообучение SigLIP на данных каталога |
| `04_index_and_eval.ipynb` | Построение FAISS-индексов, OCR-реранжирование и оценка на eval-наборе |

## Данные и результаты

Исходные датасеты, кропы, промежуточные эмбеддинги и логи обучения не хранятся в репозитории из-за размера. Для продакшен-запуска нужны только готовые веса и индексы из `backend/artifacts/`, скачанные через Git LFS.

## Ограничения

- Подготовка и eval могут выполняться на CPU, но долго.
- Дообучение YOLO и SigLIP требует GPU; для комфортной работы желательно не менее 4 ГБ VRAM.
- Перед повторным обучением нужно проверить пути к исходному датасету и не перезаписывать рабочие артефакты, которые использует API.

Параметры и ожидаемые runtime-файлы зафиксированы в [`../app/config.py`](../app/config.py). Архитектура сервиса описана в [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
