# Своё Вино — Wine Scanner

Проект разделён по зонам ответственности:

- `frontend/` — мобильный прототип сайта: каталог, карточка вина, экран сканирования и запросы к API.
- `backend/` — API, работа с датасетом, выдача фотографий и вызов ML-модуля.
- `ml/` — распознавание бутылки по изображению и связанные модели.
- `docs/` — договорённости между частями проекта.

Фронт обращается только к бэкенду. Бэкенд вызывает ML-код и возвращает фронту данные в формате, описанном в [черновике API](docs/API.md). ML-код не нужно вызывать напрямую из браузера.

Во фронт импортированы проверенные пары «фото + описание» из CSV и архива. Каталог работает локально, без ML и бэкенда. Распознавание этикетки по фото будет подключено через API. Инструкция по запуску находится в [frontend/README.md](frontend/README.md).

Текущий `main.py` — исходный шаблон PyCharm. Он оставлен на месте, чтобы не затрагивать существующие изменения.
