# Frontend — «Своё Вино»

Статический мобильный интерфейс на HTML, CSS и JavaScript. Сборка и npm-пакеты не нужны.

## Запуск

```powershell
python -m http.server 5173 --directory frontend
```

Откройте [http://localhost:5173](http://localhost:5173).

Для просмотра только интерфейса без API задайте в `config.js` пустую строку:

```js
window.WINE_API_BASE = '';
```

В этом режиме каталог читается из `catalog.json`. Для полного приложения используйте Docker Compose из корня репозитория: Nginx разместит фронтенд и проксирует API на одном домене.

## API-клиент

В [`config.js`](config.js) задано:

```js
window.WINE_API_BASE = '/';
```

Это адрес API для Docker и деплоя через Nginx. Фронтенд использует только следующие маршруты:

| Метод | Путь | Использование |
| --- | --- | --- |
| `GET` | `/wines` | Загрузка каталога |
| `GET` | `/wines/{id}` | Догрузка карточки вина |
| `POST` | `/predict` | Фото в multipart-поле `image` |

При запуске FastAPI отдельно от фронтенда, без Nginx, задайте полный адрес, например `window.WINE_API_BASE = 'http://localhost:8000'`.

## Функции интерфейса

- Каталог, поиск и фильтры.
- Карточка вина, похожие вина и сравнение.
- Камера через `getUserMedia`, снимок и загрузка из галереи.
- Экран проверки фотографии и результат ML-распознавания.
- Выбор из кандидатов ML, если `confidence < 0.65` или `gap < 0.08`.
- Избранное, история, подборки и винный дневник в `localStorage`.
- Паспорт вкуса, рекомендации и цифровой сомелье на данных локального каталога.

Личного аккаунта, регистрации и авторизации нет.

## Каталог и фотографии

`catalog.json` содержит 2 103 карточки. `local-image-map.js` сопоставляет каждую карточку с локальным файлом в `assets/wines/`; это гарантирует показ фотографий независимо от внешнего CDN.

Поля карточки: `id`, `name`, `winery`, `region`, `category`, `color_description`, `image_url`, `description`, `grapes`.

## Камера

Браузер запрашивает доступ к основной камере устройства. Для её работы нужен `localhost` или HTTPS. Если камера недоступна либо доступ запрещён, пользователь может выбрать изображение из галереи.
