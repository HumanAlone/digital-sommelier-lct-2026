# Frontend — «Своё Вино»

Мобильный прототип по присланным экранам Figma. Статический HTML/CSS/JavaScript, без сборки и сторонних пакетов.

## Запуск

Из корня проекта:

```powershell
python -m http.server 5173 --directory frontend
```

Откройте `http://localhost:5173`.

## Подключение бэкенда

В `config.js` задан `window.WINE_API_BASE = '/'`: запросы идут на тот же домен и по тому же протоколу, что и сайт. Nginx передаёт их в backend. Это работает с телефона и после деплоя без изменения адресов. Фронт ожидает маршруты из `../docs/API.md`:

Простой `python -m http.server` не проксирует API. Для просмотра только фронта задайте пустую строку в `config.js`; для полного приложения используйте Docker Compose с Nginx.

- `GET /wines` — `{ "items": [...] }`
- `GET /wines/{id}` — полная карточка вина
- `POST /predict` — фото в поле `image`, ответ `{ "slug": "..." }`

При пустом адресе каталог загружается из `catalog.json`: 2 103 вина с описаниями и доступными фотографиями из переданного датасета. Фронт не имитирует распознавание. Избранное, история, подборки и дневник пока хранятся в `localStorage` браузера. Когда появится бэкенд, каталог можно получать через API.

Личный кабинет доступен без аккаунта. Избранное, история, подборки и дневник сохраняются в этом браузере.

Повторить импорт можно командой `python scripts/import_wines.py "C:/путь/к/Датасет"` из корня проекта. Нужен установленный WinRAR (`UnRAR.exe`). Скрипт пропускает изображения, для которых связь с записью неоднозначна; исходные CSV и архивы не меняет.

Сканер открывает камеру через `getUserMedia`, показывает живое изображение и сохраняет кадр по кнопке «Сделать фото». Камера требует разрешения браузера и работает на `localhost` либо по HTTPS. При отказе или отсутствии камеры можно запустить системную камеру телефона или загрузить снимок из галереи.

Поля из текущего каталога: `id` (Slug из CSV), `name`, `winery`, `region`, `category`, `color_description`, `image_url`, `description`, `grapes`. Дополнительные поля `vintage`, `country`, `sweetness`, `abv`, `food_pairings` можно будет показать, если они появятся в API. Если бэкенд отдаёт другие имена, достаточно адаптировать `api.js`.
